  1. Every new sensor deployment starts without labels.
  2. A model trained on one stream breaks when the sampling rate, the channel count or the noise changes.
  3. Labelled anomalies are rare, so supervised models see a few dozen positives at most.

Kestrel turns any multivariate stream into one embedding per time step, so a linear probe can read any downstream label from it.

Limitations

Kestrel saw only public datasets in pretraining, and seven domains do not cover every sensor. Streams sampled faster than 2 kHz were not part of pretraining. The five tasks use linear probes; fine-tuning was not evaluated.

One pretrained encoder can read many kinds of sensor streams without being trained again.
