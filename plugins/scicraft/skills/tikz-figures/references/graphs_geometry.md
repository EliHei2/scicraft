Discrete structures (graphs, GNNs, graphical models, MDPs) and geometric diagrams
(equivariance, frames, point-cloud transforms). Uses `base` and the palette of
`assets/preamble.tex`. Snippets go between the preamble and `\end{document}`. A graph or
tree that stands for what a method computes is generated by that method's code
(`generators.md`); the hand-placed coordinates below are for generic illustrations.

## 1. Generic graph

Place nodes by hand or on a circle with `\foreach`. Edges thin gray; highlight one node
in accent.

```latex
\begin{tikzpicture}[base,
    gnode/.style={var, minimum size=6mm, fill=cloud}]
  \node[gnode] (1) at (90:1.4)  {};
  \node[gnode] (2) at (162:1.4) {};
  \node[gnode] (3) at (234:1.4) {};
  \node[gnode] (4) at (306:1.4) {};
  \node[gnode, fill=accent!25, draw=accent!75!black] (5) at (18:1.4) {$v$};
  \foreach \a/\b in {1/2,2/3,3/4,4/5,5/1,1/3,2/5} \draw[slate, line width=0.6pt] (\a)--(\b);
\end{tikzpicture}
```

## 2. Message passing / GNN update

Center node receiving messages from neighbors, then an update box. This is the canonical
GNN figure.

```latex
\begin{tikzpicture}[base, node distance=12mm,
    gnode/.style={var, minimum size=6mm, fill=cloud}]
  \node[gnode, fill=accent!25, draw=accent!75!black] (i) {$i$};
  \node[gnode, above left=8mm and 12mm of i] (a) {};
  \node[gnode, left=14mm of i] (b) {};
  \node[gnode, below left=8mm and 12mm of i] (c) {};
  \foreach \n in {a,b,c} \draw[->, contrast, line width=0.7pt] (\n) -- node[note,sloped,above]{$m_{\n\to i}$} (i);
  \node[block accent, right=14mm of i] (upd) {$h_i' = \phi(h_i, \sum m)$};
  \draw[flow] (i) -- (upd);
\end{tikzpicture}
```

## 3. k-NN graph on a point set

Points with edges only to nearby points. Connect explicit pairs here (computing true kNN in
TikZ is awkward; for a real point set compute the edges in Python, see `generators.md`).

```latex
\begin{tikzpicture}[base]
  \foreach \i/\x/\y in {0/0/0, 1/0.8/0.3, 2/0.4/0.9, 3/1.4/0.8, 4/1.0/-0.5, 5/-0.4/0.6} {
    \coordinate (p\i) at (\x,\y); \fill[ink] (p\i) circle (1.2pt);
  }
  \foreach \a/\b in {0/1,0/2,0/5,1/3,1/4,2/5,2/3} \draw[mist, line width=0.5pt] (p\a)--(p\b);
\end{tikzpicture}
```

## 4. Plate notation

Repeated variables inside a labeled rectangle; observed nodes shaded. Classic LDA-style
PGM.

```latex
\begin{tikzpicture}[base, node distance=12mm,
    latent/.style={var, minimum size=8mm},
    obs/.style={var, minimum size=8mm, fill=mist!50}]
  \node[latent] (theta) {$\theta$};
  \node[latent, right=of theta] (z) {$z_n$};
  \node[obs, right=of z] (x) {$x_n$};
  \draw[flow] (theta) -- (z); \draw[flow] (z) -- (x);
  % plate
  \node[draw=slate, rounded corners, fit=(z)(x), inner sep=8pt] (plate) {};
  \node[grouptitle, below right=1pt and 2pt] at (plate.south west) {$n=1\dots N$};
\end{tikzpicture}
```

## 5. Markov chain / MDP

States in a row with transition arcs; an action/reward annotation. Self-loops with `loop`.

```latex
\begin{tikzpicture}[base, node distance=18mm,
    state/.style={var, minimum size=9mm, fill=cloud}]
  \node[state] (s0) {$s_t$};
  \node[state, right=of s0] (s1) {$s_{t+1}$};
  \node[state, right=of s1] (s2) {$s_{t+2}$};
  \draw[flow] (s0) to[bend left=25] node[note,above]{$a_t$} (s1);
  \draw[flow] (s1) to[bend left=25] node[note,above]{$a_{t+1}$} (s2);
  \draw[flowfaint] (s0) to[loop below] node[note,below]{$r_t$} (s0);
\end{tikzpicture}
```

## 6. SE(3) / rotation-equivariance diagram

The "same output regardless of input pose" idea: a small shape, a rotation
arrow, and the rotated copy, with an `=` after the model maps both to the same result.

```latex
\begin{tikzpicture}[base, node distance=10mm]
  % object 1
  \begin{scope}
    \fill[accent!60] (0,0) -- (0.6,0.1) -- (0.4,0.7) -- cycle;
    \fill[contrast!60] (0.6,0.1) circle (2pt);
  \end{scope}
  \node[note] at (0.3,-0.6) {input};
  % rotation arrow
  \draw[->, slate, line width=0.8pt] (1.2,0.3) arc (-30:210:4mm);
  \node[note] at (1.5,1.1) {$R\in SO(3)$};
  % object 2 (rotated)
  \begin{scope}[shift={(3,0.3)}, rotate=55]
    \fill[accent!60] (0,0) -- (0.6,0.1) -- (0.4,0.7) -- cycle;
    \fill[contrast!60] (0.6,0.1) circle (2pt);
  \end{scope}
  % model maps both to same output
  \node[block accent, right=14mm of {(3.6,0.3)}] (f) {$f$};
  \node[right=10mm of f] (out) {$f(x)=f(Rx)$};
  \draw[flow] (3.9,0.3) -- (f);
  \draw[flow] (f) -- (out);
\end{tikzpicture}
```

## 7. Local coordinate frame

## 8. Set / permutation invariance

Elements → shared encoder → symmetric pool → output, showing order doesn't matter.

```latex
\begin{tikzpicture}[base, node distance=6mm]
  \foreach \i in {1,2,3} \node[var, minimum size=6mm] (x\i) at (0,{-(\i-2)*8mm}) {$x_{\i}$};
  \node[block, right=12mm of x2] (phi) {$\phi$};
  \node[op, right=10mm of phi] (sum) {$\sum$};
  \node[block accent, right=10mm of sum] (rho) {$\rho$};
  \foreach \i in {1,2,3} \draw[flow] (x\i) -- (phi);
  \draw[flow] (phi) -- (sum); \draw[flow] (sum) -- (rho);
  \node[note, below=5mm of phi] {permutation-invariant};
\end{tikzpicture}
```

## 10. Serif-look graphs: gray edges, navy nodes

The graphs above restyled with the serif theme's ink hierarchy. The grammar is unchanged;
only the ink moves:

- **Edges stay gray support ink** (`annot`, about 0.7 pt), never an accent. An undirected
  edge is a plain line without an arrowhead.
- **Nodes are the navy family**: `draw=navy` outline, `accentL` fill. The one accent is a
  single highlighted node or path, promoted to a solid `navy` fill with a white label.
- **Arrows follow the hierarchy**: aggregated messages are gray (`agg`), the one primary
  data-flow arrow is black (`spine`).
- **Source and target node sets use the two-tone rule**: `navy` source, `accentMd` target;
  lightness alone encodes direction. `contrast` only for a real two-condition set.
- **A stochastic trajectory on a graph** is a fan of thin gray `traj` strands with exactly
  one highlighted `trajhi` path on top, over a black time axis.

### 10a. Generic graph (navy nodes, gray edges, one accent node)

```latex
\begin{tikzpicture}[
    gnode/.style={draw=navy, line width=0.9pt, circle, fill=accentL,
                   minimum size=6mm, inner sep=0pt, text=navy},
    gnodehi/.style={gnode, fill=navy, text=white}]   % the ONE accent node
  \node[gnode]   (1) at (90:1.5)  {};
  \node[gnode]   (2) at (162:1.5) {};
  \node[gnode]   (3) at (234:1.5) {};
  \node[gnode]   (4) at (306:1.5) {};
  \node[gnodehi] (5) at (18:1.5)  {$v$};
  \foreach \a/\b in {1/2,2/3,3/4,4/5,5/1,1/3,2/5}
    \draw[annot, line width=0.7pt] (\a)--(\b);          % grey support edges, no arrowhead
\end{tikzpicture}
```

### 10b. Message passing (gray aggregation, one black dataflow arrow)

The §2 GNN figure in the serif theme's ink: neighbor messages are gray support arrows (`agg`), the
center node is the accent, the update box is the rounded thick-black-outline `opbox`, the
single dataflow arrow into it is black (`spine`), and the serif update equation is pinned
above with a gray role caption below.

```latex
\begin{tikzpicture}[node distance=12mm,
    gnode/.style={draw=navy, line width=0.9pt, circle, fill=accentL,
                   minimum size=6mm, inner sep=0pt, text=navy},
    gnodehi/.style={gnode, fill=navy, text=white}]
  \node[gnodehi] (i) {$i$};
  \node[gnode, above left=8mm and 13mm of i] (a) {};
  \node[gnode, left=15mm of i]               (b) {};
  \node[gnode, below left=8mm and 13mm of i] (c) {};
  \foreach \n in {a,b,c}
    \draw[agg] (\n) -- node[note,sloped,above]{$m_{\n\to i}$} (i);  % grey support arrows
  \node[opbox, right=15mm of i] (upd) {$h_i'$};
  \node[note, below=2pt of upd] {update};
  \draw[spine] (i) -- (upd);                                           % ONE black dataflow arrow
  \node[eq, above=4mm of upd] {$h_i' = \phi\!\big(h_i,\textstyle\sum_j m_{j\to i}\big)$};
\end{tikzpicture}
```

### 10c. Source/target node sets + stochastic trajectory on a graph

Two-tone dot sets (navy $\mu_0$ left, `accentMd` $\mu_1$ right) joined by a gray
trajectory cloud with one highlighted navy example path, applied to a
source→target transport over a point/node set. (For a fresh random fan each compile drop
the seed; `\pgfmathsetseed{<n>}` before the loop pins it.)

```latex
\begin{tikzpicture}
  % source node set (navy mu_0) at left
  \foreach \p in {(0,0.05),(0.05,0.45),(-0.1,-0.35),(0.15,0.2),(-0.05,-0.05)}
    \fill[navy] \p circle (2.4pt);
  \node[navy, font=\figL] at (0,-0.85) {$\mu_0$};
  % target node set (mid-blue mu_1) at right -- accentMd, NOT pale accentL
  \begin{scope}[xshift=42mm]
    \foreach \p in {(0,0.1),(0.1,0.4),(-0.1,-0.3),(0.15,-0.05),(-0.05,0.25)}
      \fill[accentMd] \p circle (2.4pt);
    \node[accent, font=\figL] at (0,-0.85) {$\mu_1$};
  \end{scope}
  % grey stochastic-trajectory cloud (the Brownian cloud idiom)
  \foreach \i in {1,...,24}{
    \pgfmathsetmacro{\j}{0.7*rnd-0.35}
    \draw[traj]
      (0,\j) to[out=15,in=165]
      (2.1,{\j+0.3*rnd-0.15}) to[out=-15,in=195]
      (4.2,{\j*0.4+0.2*rnd-0.1});}
  \draw[trajhi]                                          % ONE highlighted example path
    (0,0.04) to[out=15,in=165] (2.1,0.16) to[out=-15,in=195] (4.2,0.02);
  \node[navy, font=\figL] at (2.6,0.7) {example path};
  \draw[ink, line width=1.1pt, ->, >={Stealth[length=2mm]}]
    (0,-1.25) -- (4.2,-1.25) node[midway,below,font=\figL]{time};
\end{tikzpicture}
```

## 11. Styling notes

- Nodes on a circle: `\node at (<angle>:<radius>)`. Even spacing = `360/n` steps.
- Keep edges gray (`slate`/`mist`), nodes neutral, and accent only the focal node/path.
- For directed PGMs use `flow`; for undirected graphs use a plain gray line (no arrowhead).
- Plates: `fit` the repeated nodes, label in the SE/SW corner with `grouptitle`.
- `loop above`/`loop below` need the `arrows.meta` + default automata-ish behavior; set
  `every loop/.style={->}` if the arrowhead is missing.
- Equivariance figures land best when the two poses are visibly different but the shape is
  obviously "the same object": reuse the exact same drawing code inside a rotated scope.
- Serif look (section 10): gray edges, navy nodes, one solid navy node or path.
