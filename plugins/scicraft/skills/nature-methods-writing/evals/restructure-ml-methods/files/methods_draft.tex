\section{Online Methods}

This section describes the full methods account for RowSet. It is worth noting that every choice below was made carefully so that the reported results are auditable.

\subsection{Model architecture}

RowSet is a 12-layer transformer with 8 attention heads and a hidden size of 512 --- a deliberately small model --- that we pretrain on OpenML-CC18 and the TabArena suite. Each numeric feature is quantile-binned into \texttt{n\_bins} = 64 bins and each bin is embedded; categorical features use a learned embedding per level (see Fig.~2a). The row representation is the mean of the column tokens, as shown in Figure 1b.

The prediction for row $i$ is
\begin{equation}
\hat{y}_i = W \, \mathrm{mean}_j \, h_{ij} + b .
\label{eq:head}
\end{equation}

\subsection{Training}

We train with AdamW at a learning rate of $3\times10^{-4}$ with 5,000 warmup steps and cosine decay over 200,000 steps, batch size 256 and dropout 0.1. We note a discrepancy: the weight decay (\texttt{weight\_decay}) is 0.01 in the code default versus 0.05 in our runs. Every configuration was trained with five seeds (0 to 4). The objective is the cross-entropy
\begin{equation}
\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N} \log p_\theta(y_i \mid x_i).
\label{eq:loss}
\end{equation}
The splits are fixed in advance and were never tuned on test data. All runs used one NVIDIA A100 80 GB GPU and took 31 h each.

\subsection{Evaluation}

We evaluate on 72 classification datasets from OpenML-CC18 with the benchmark package tabbench. For OpenML-CC18 we drop rows with missing labels, standardise numeric columns using training-fold statistics and use 10-fold cross-validation with the fixed splits. For TabArena we drop rows with missing labels, standardise numeric columns using training-fold statistics and use the suite's official splits. The splits are fixed in advance and were never tuned on test data. Accuracy and ROC AUC are computed per dataset and methods are compared by mean rank. RowSet outperforms all baselines with a mean rank of 2.1 (P = 0.003, Wilcoxon signed-rank test with Holm correction).

Baselines were XGBoost and CatBoost, each tuned with 100 random-search trials per dataset.
