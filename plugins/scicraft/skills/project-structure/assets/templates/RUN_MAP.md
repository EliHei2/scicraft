# Run map

One row per (unit, variant): a unit is what a run is about (a dataset, a benchmark task, a cohort), a variant is what is tried on it (a model, a method, a config). Update it in the same edit as any run, config or status change. No nested per-step maps.

Status: `planned`, `submitted`, `done`, `validated`, `aggregated`; or `failed`, `oom`, `archived`. `Synced` is `yes` once the run's lessons are folded into `guidelines/`, and `-` until then.
