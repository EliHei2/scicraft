# GUARDRAILS

Owns one question: what must never happen in {{NAME}}. Each rule prevents one specific failure that would make a result wrong, void or untraceable, or damage what belongs to someone else, with nothing looking wrong when it happens. These are invariants. A setting that is safe to tune lives in `DESIGN.md`; a convention lives in `GUIDELINES.md`.

If a rule must be broken to make progress, stop and tell the lead. Never break one silently. Ids are stable: a rule that no longer applies is marked RETIRED with its date and reason, and its id is never reused.

## 0. What belongs to other people

- **G0. Never write to, and never delete from, any path outside this project's own trees.** Raw stores, shared datasets and other people's folders are read-only. Prevents: a lost or changed file that cannot be recovered or attributed. Check: [the allowlist of the job wrapper and of `scripts/sync.sh`, or convention].

## 1. Provenance and results

- **G1. Code and data never mix.** Data, checkpoints and outputs stay out of git; a small baseline is tracked only under `reference/`. Prevents: a repository that cannot be pushed, and results nobody can tie to code. Check: `git status --short` and `git check-ignore -v <file>`.
- **G2. Every path is set once**, in `configs/paths.env`. Prevents: a run that reads a stale copy. Check: search for absolute paths outside that file.
- **G3. One results root per run profile, with `config.json` first and `manifest.json` last, and nothing overwritten.** A superseded output moves to `results/archived/<YYYY-MM-DD>_<reason>/`; the run gets its `RUN_MAP.md` row in the same edit. Prevents: a result whose settings or code version cannot be named. Check: every cited root has a manifest (`store.py check`, or `run_manifest.py`).
- **G4. Smoke runs write to `scratch/`.** Prevents: a test output cited as a result. Check: `ls results/runs/`.
- **G5. Every copy into the project gets a `PROVENANCE.md` row in the same edit.** Prevents: an input that cannot be traced or refreshed. Check: `provenance.py check`.
- **G6. No number is typed into prose by hand.** It is generated by a script, or it carries `[VERIFY]`. Prevents: a count that drifts between the result file and the text. Check: [the preflight that compares generated blocks, or convention].
- **G7. Failures stay in the log.** `experiments/EXPERIMENTS.md` keeps every attempt with its outcome label. Prevents: a dead end walked twice, and a negative result reworded into a win. Check: convention.
- **G8. The laptop writes, the remote computes; `.git` never travels and sync never deletes.** Prevents: a lost remote, and newer files overwritten on the other machine. Check: `scripts/sync.sh` refuses both.
