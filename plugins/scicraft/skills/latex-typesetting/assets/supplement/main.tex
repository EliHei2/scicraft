\section{Model, training and inference}\label{sec:model}
\method{} scores a candidate pair by cosine similarity and keeps the best
candidate,
\begin{equation}
  \hat b_t=\argmax_{b} s_{tb}.\label{eq:assign}
\end{equation}
Unless an analysis states otherwise, \method{} runs in one fixed default
configuration\label{subsec:default-config}: [encoder width $64$, $20$ epochs
with Adam~\citep{kingma2015adam} at learning rate $10^{-3}$, neighbors within
$5$\um{}]. The full parameter list is in Supplementary Table~\ref{tab:defaults}.
Residual blocks follow~\citep{he2016resnet,lecun1998gradient}.
