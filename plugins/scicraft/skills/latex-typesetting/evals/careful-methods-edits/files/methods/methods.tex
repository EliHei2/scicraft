\section{Model}\label{sec:model}
\model{} encodes each table row with a six-layer transformer of width $256$
and retrieves its $k=32$ nearest training rows in the same embedding space.
Residual connections follow~\citep{he2016resnet}. Rows are drawn from the
benchmark described in Section~\ref{sec:data}.

\subsection{Setup}\label{sec:setup}
We train for $50$ epochs with Adam~\citep{kingma2015adam} at a learning rate of
$10^{-4}$ and a batch size of $512$ rows. Training stops early when the
validation loss has not improved for five epochs. Each run takes about
\SI{3}{\hour} on one GPU.
